## 2.7 附件

这部分，大概知道它的什么东西会放在这里就行了。**我根据以往的题整理出了出现的**：

**1、字段与映射规范**

- 标准字段名与定义列表：飞书表格该建哪些列、叫什么（包括英文表示）、什么类型、什么顺序【必须完全匹配】。
- **注意：字段名、字段顺序写错直接扣分或计零分**，属于评分红线。

**2、标签 / 枚举值清单（决定输出只能取哪些值）**

**如：**

- 内容标签列表.csv：所有允许输出的内容标签及其定义，如「口味绝佳」「踩雷避坑」。（十七届样题附件一）
- 讲座分类标签列表：标签名 + 定义 + 典型示例，赛题建议导入知识库辅助分类。（十八届样题附件一）
- **输出的分类 / 标签字段必须从清单里选**。

**3、业务规则与评分规则（代码节点的计算依据）**

- 分维度评分规则：教育背景 25 分、工作经历 30 分、技能与证书 20 分、个人综合能力 25 分，以及岗位适配度百分制画像规则。（十七届省赛真题附件3–7）
- 审核逻辑与政策口径：行业准入目录、负面清单、纳税与研发占比门槛、新旧政策的时效覆盖关系。（十七届国赛真题附件1、附件6 场景）
- **这类规则通常明确要求**「**评分或计算结果由逻辑节点或代码节点执行，不得由大模型直接输出**」。（十八届规则 P3 红线）

**补充解释：十八届的样题**，**因为比较简单就直接放在了对应的模块附近解释**（**这也正是各题目的大纲模板有出入的原因所在**）

**4、默认值 / 全局变量素材（照抄配置，不要自己编）**

就是我们的 App ID、App Secret、表格链接这种，**它都会限制你要把它命名**为 app_id、app_secret、table_url 这种。

**5、输入样例与预置数据（跑通核心链路用）**

- 示例简历 3 份：作为我们测试的输入素材，原先样题简单，都是文本，这里是PDF文件这种会单独在赛题压缩包里面。（十七届省赛真题附件8）

- 企业基础信息表 Base_Info、企业研发与纳税信息表 Financial_Data：**预置在飞书表里、供 API 跨表查询的测试数据，以统一社会信用代码为主键**。（十七届国赛真题附件3、4）
- **效果图示例：开场白、全局变量、执行流程长什么样**，**用于对齐交互流程一致性评分**。（十七届国赛真题附件8）

**6、接口教程与速查（HTTP 请求节点怎么配）**

- 飞书多维表格核心 API 速查：获取 tenant_access_token 示例。（十七届省赛附件9；国赛附件7）

- 飞书多维表格 API 调用简明教程：创建自建应用、拿 App ID 与 App Secret、开通权限、获取 token、新增记录**请求示例**。（十七届样题附件三；十八届样题附件三）

**注意：真题部分的请求示例，已经在效果图里面了，基本上只剩下 获取 access_token 的示例。这样就意味着我们在设计提示词那些的时候 转向了 根据这图片里面的响应效果。**

**7、测试用例集（自测 + 机器评分依据）**

- 智能体测试指令用例集：按实操流程给出输入与预期结果。（省赛附件10；国赛附件6）
- test_cases.txt：点评文本用例，标注简单正面、简单负面、中性/混合等场景类型。（十七届样题附件四）
- 测试用例文本：讲座公告 19 条（含 1 条非讲座内容），每条附重要程度评分预期结果，用于测分类、提取与异常识别。（十八届样题附件四）

**总结下来这四个：标签 / 枚举清单** + **字段映射表** + **API 调用教程** + **测试用例集**。**两份样题和两份真题都出现**，**第十八届正式题大概率沿用**。

**正式比赛读附件：**

1、字段名与顺序、标签枚举、默认值、预期结果都是标准答案，**照抄不能自创**；

2、**字段映射表决定建表和输出 JSON**，API 教程决定 HTTP 节点配置（这部分多练就熟了不用管，因为很可能沿用十七届只有一个 获取 access_token 示例，没用）；
