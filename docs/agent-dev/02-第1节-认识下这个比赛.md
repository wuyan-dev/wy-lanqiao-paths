# 一、蓝桥杯到底是个什么比赛

- **全称：**蓝桥杯全国大学生软件和信息技术大赛，面向全国高校在校大学生。
- **宗旨：**立足行业，突出实践，广泛参与，促进就业。
- **规模：**办了17届，全国2100多所高校参赛，本科院校覆盖率超过90%，累计参赛170万人。
- **含金量：**

  - 连续多年入选中国高等教育学会“全国普通高校学科竞赛排行榜”；
  - 被江苏、四川、河北、江西、山西、广西、贵州、海南、新疆、宁夏、黑龙江等10多个省市自治区纳入省级大学生竞赛名录。
- **命题逻辑：**以岗定标 → 以标设赛 → 以赛促学。**说白了，赛题是照着企业岗位能力要求出的**，**“赛题即岗位、竞赛即实战”**。
- **上一届（17届）的情况：**25万人报名，32%是大一选手，25%是第二次参赛，10000+硕士博士。说明这比赛不是大三才想起来打的，早开始、打两次都很正常。

# 二、参加比赛的好处

- **校内加分：**大多数高校的**综合测评**、**推免加分**细则，都把蓝桥杯作为重要依据。（**有一次综测加分，定了规则省级奖项才能加，校级的都不行，那次给我整爽了；研究生推免，我的方向是就业，但是我同学他也参加蓝桥杯，而且现在已经保研上了**）
- **保研/考研复试：**面试时能体现你的技术思维和解决问题的能力，这是导师关心的。
- **技术能力：**对标企业岗位要求和行业标准，**练的是真实情境下解决问题的能力**。（**深有体会，每次竞赛的时候都能很清晰的感受到自己的边界卡点所在**）
- **就业：知名企业广泛认可**，一张国赛获奖证书就是技术能力最直接的证明；**大赛还有就业护航计划、企业联盟、名企内推**。（**我亲身经历过，老师联系了我帮我内推，给我鼓励，还有群：每日分享企业岗位，面试要点这些，还提供各种资讯**）
- **数据支撑（麦可思《蓝桥杯大赛学生发展质量跟踪评价报告》，5万多份问卷）：**

  - 本科参赛毕业生毕业一年后工作与专业相关度83%，比同类专业参照系高14%以上；
  - 67%的选手就业去向集中在技术与应用岗位；
  - 毕业一年后平均月收入8952元，高于全国同类毕业生；
  - 2025届本科参赛毕业生近五成在读研（境内硕士41%、境内博士2%、境外硕士2%、境外博士1%）。
- **证书：**省赛一二三等奖→初级证书，决赛一二三等奖→中级证书（工信部人才交流中心、中国软件行业协会赛证融通）。（**这个去认证也是需要交不少钱的，我没有弄**）

# 五、奖项、晋级和证书

- **省赛：**一二三等奖比例10%、15%、25%，总获奖不超过50%；**省赛一等奖进全国总决赛**。（**获得一等奖就默认有了进入全国总决赛的资格，但是只是资格，还需要再次交钱报名才能去打决赛**）
- **总决赛：一二三等奖比例10%、25%、40%，总获奖不超过75%**；国赛一等奖比例从5%提高到10%，奖品总额超过百万。
- **赛证融通：**省赛一二三等奖→初级；决赛一二三等奖→中级。
- **赛场回放报告：**赛后给软件赛选手一份报告，不排名、不唯分数，看的是提交时间轨迹、尝试题目类型、知识点热力图、算法能力诊断、定制进阶路线。拿来做复盘很好用。（**这个我没用过，可以试试看**）

- **全面拥抱AI：**调整/新增“AI模型应用开发”赛项。

  - 不是简单调接口，也不要求从零训练大模型；
  - 考的是模型部署与调用、Prompt与响应策略优化、RAG知识增强、数据适配、轻量级模型优化、AI应用系统开发；
  - 支持PaddlePaddle、MindSpore、ModelScope等国产AI生态；
  - 和数据分析、智能体开发形成“数据分析—AI模型应用—智能体开发”的递进。
