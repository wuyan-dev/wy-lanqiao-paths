<callout emoji="🐱">
**你可能担心的"两次主题不一致"，会不会带来坏处**。**不会的**。
**这两个节点产出的东西，性质完全不同**：
- **内容解析与提取节点：**产出的是要**写进飞书表的字段**。**要忠实原文、准确完整、缺失填空**。它是**抄录员**。
- **主题描述节点：**产出的**是喂给知识库搜索的检索词**。**它不写表、不给人看、不进任何交付物**，**唯一任务是跟标签定义的语义空间对齐**。它是**检索员**。它属于的分支要进飞书字段的是后面分类节点分类出的结果，才是要填进表格的字段。
</callout>

```Python
                                              」
                   └→ 主题描述 → 知识库搜索 → 分类判断

```

**还有一个本质的知识，官方没有说明，只是叫我们根据讲座主题来作为查询索引，但是原因是什么没说。**

**知识库搜索节点，本质上是 靠语义检索的，就是按意思来检索的**。**所以，实质上可以直接传入用户输入的公告原文给知识库搜索节点进行检索判断属于哪一个分类**。

**但是，原文中涵盖了大量的无用信息，会导致检索不出我们想要的，而且还会增加 大量的 token 响应，消耗时间**。**所以**，我们的**主题描述节点 就是把核心的内容提取出来，只把这些交给知识库搜索节点去查询内容，命中率就更高，命中率高，消耗的 token**（用户输入的内容变成了主题描述提取的核心内容）**少**，**响应时间就慢**（节点内容模型思考的时间少）。
