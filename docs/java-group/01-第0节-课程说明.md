### 一、这是什么，不是什么

- 这是我从 0 到拿奖的思路攻略，加我自己从头梳理的一份 Java 编程基础笔记，加一路用到的工具。
- 它不是系统课程。具体的知识点，有人比我做得更好，我不重复造轮子。8 天的 Java 基础网课我给了网盘链接，你自己去学，我只把我学完之后整理的笔记放这儿给你参考。
- 你缺的最重要的一个东西，从来不是知识点，而是**认知**；认知之后，是**执行力**；执行力之后，才轮到**对知识的理解和掌握程度**。说谁有天赋、谁没天赋，都是扯淡。

### 三、适合谁，不适合谁

适合：不想报班（或者报不起）、愿意自己看官方文档、自己定计划、自己刷题的人。**第一次参赛、连环境都还没装过的，也从这儿开始——走路线 A，第 1 到第 6 节就是给从 0 开始的人写的。** 对于一个上大学都要借贷款读的我来说，走的就是这条野路子。

不适合：想被人全套喂着学、只想囤资料不看的人。我买了那些资料，基本上看一眼就给我整焦虑了，别再走一遍。

### 五、我的第一原则：找对标

我做事的第一原则，就是**找对标**。

如果你想到达一个地方，最快的方式，就是找到一个已经到过那个地方的人，看他是怎么到的。你还在迷迷糊糊、啥也不知道的时候，先照着他的做，至少不会一开始就跑偏。

但我没有只找一个。原因很简单：网上的资料太散了，即使是一些获奖朋友分享的经验和备赛过程，其实也不够全面。看完之后，脑袋里好像学到了什么，但又好像还是不知道该怎么去做。

于是，我就找了很多例子，还总结出了一套自己的流程：

> 先察觉自己的问题 → 抓住那个问题（哪怕它还比较模糊）→ 上网搜，找对标 → 学习（我的做法是把他的流程自己手打一遍，记在自己的飞书笔记里）→ 学出一点感觉、更清晰了 → 审视现在的自己还缺什么 → 继续搜 → 了解得差不多了，就开始干。

这套流程几乎适用于所有没什么大钱报班，想走些邪修的路子的人了。

我以前在这上面花的时间比较多。因为要做计划，就必须了解得足够多，计划成功的概率才会更大。但留给练习的时间就短了——不然，我也不会只是国家三等奖。

所以，**越早准备越好**。

### 六、几条我自己踩出来的大原则

- **一定要学会看官方的通知，看官方的文档。** 有很多人拿不到奖项，都是只停留在知道这个比赛，其他就啥都不知道了，怎么备赛也不知道；B 站上那些搜来的，也都是二次创作来的，有的还是为了引流去报班。想拿到好成绩，还要走得远，必须紧贴着官方文档，得会自己研究、做计划，然后就是执行力、专注度。（第 2 节）
- **认准蓝桥的题库就够了，别变来变去。** 你刚刚熟悉这个，又去那个，那前面的都白费了。况且这是蓝桥官方自己的题库啊。（第 2 节）
- **计划按自己的能力定。** 哪些可做、哪些不可做、哪些可做的都保底了的情况下可以去试一试，这个就是非常核心的拿分策略。（第 4 节）
- **两道填空题的思路必须吃透，编程题前两道靠暴力先保底。**（第 4 节）
- **代码就可以当作计算器**，比计算器还灵活，这也是编程的本质所在。（第 4 节）
- **按数据规模拿部分分。会正解写正解，不会正解写暴力循环骗分。**（第 6、7 节）
- **刚开始不会很正常**：先自己读一下题目，思考一两分钟，直接让 AI 给解题思路和代码（要有注释以及分析），你直接去理解是如何这么做的；慢慢的自己写，理解之后不看代码再编写一遍。（第 4 节）
- **想变强很简单，只需要：不停刷题、刷题、刷题。刷完之后也要总结自己的知识体系/代码模版。**（第 2、7 节）
- **我能帮你的，是尽可能帮你打开认知，给你一份经验包和可用的工具，减少你在费时费力的事情上的探索时间。** 刷题、做适合自己的计划、自己亲自把历年真题全部研究一遍，这些必须你自己去做一遍。

### 七、你该是自己的主人

所以，我对你的判断是：**你应该是自己的主人，尽可能去掌控这一切。** 至少从概率上，你这样做是对的。即使最后没达到目标，你也已经超越了大多数人。

### 八、我自己的目标和结果

我当时定的目标是国二。原本想定国一，但只有仅仅两周左右的时间准备国赛，自己都感觉实在上不去，所以就定了个国二，最后拿了国三。

那两周，是包括我研究历年所有真题的时间在里面的。研究完之后，我还要制定计划。当时我给自己定的计划是：**把最近三年的真题吃透，基本上就稳国二**；如果真的吃透，说实话，国一都是很有可能的。

而我当时的掌握程度，只是把近三年的真题过了一遍，仅仅停留在"有一个大概的认知"的层面。至于实力的积累，还是要靠自己探索，靠所有认知的提升和练习的程度。而且有些题，比如比较难的，也不算是自己写出来的——思考了一番，写不出来，就直接问 AI，然后自己再写一遍。
