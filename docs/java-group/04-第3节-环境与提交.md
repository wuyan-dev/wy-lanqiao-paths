## 7、补充：区分 eclipse 与 jdk

**这里解释一下：eclipse 和 JDK 的各自定位：**

<callout emoji="👉">
**JDK（Java Development Kit，Java 开发工具包）​**
干所有实际工作的底层工具集，核心三件事：
- javac 编译器：把你写的 `Hello.java`（人看的文本）翻译成 `Hello.class`（机器能执行的字节码）
- JVM 虚拟机：实际运行字节码的程序，Java“一次编写、到处运行”靠的就是它
- 标准类库：官方自带的成千上万个现成工具（读文件、连网络、排序……），不用你从零造轮子
它不提供任何“写代码”的舒适感——纯 JDK 开发就是记事本写代码 + cmd 里敲 `javac`、`java` 命令。
**Eclipse（IDE，集成开发环境）​**
纯粹为了让你写得快、错得少、查错容易的外壳：
- 编辑器：语法高亮、自动补全、报错红线提示
- 一键运行/调试：点一下按钮，它在背后替你调用 JDK 的 javac 和 JVM
- 项目管理：几百个源文件、各种配置帮你组织好
- 断点调试：程序卡在哪一步、变量值是多少，一目了然
**注意它的本质：**Eclipse 自己不会编译和运行任何 Java 程序，每次点“运行”，它都是在幕后喊 JDK 来干活。
</callout>

# 03|实际比赛时候交形式

## 1、填空题

只是提交一个答案，一个结果。将自己算出的那个结果复制粘贴过去。

## 2、编程题

用例子说明，比如这道题：

题目描述：**给定一个字符串 s，输出字符串中单词的数量。**

输入格式：**一个字符串，其中单词由空格分隔。**

输出格式：**字符串中单词的数量。**

输入样例：the quick brown fox

输出样例：**4**

所以，复制提交过去的代码是这样的：

```Java
import java.util.Scanner;

public class Main {
        public static void main(String[] args) {
                // 接收输入数据
                Scanner sc = new Scanner(System.in);
                String s = sc.nextLine();                          // 读入整行
                String[] words = s.trim().split("\\S+");  // 按一个或多个空白字符切
                // 注意：若字符串全是空格，split 会返回 [""]，需要特判
            System.out.println(s.trim().isEmpty() ? 0 : words.length);

        }

}
```
