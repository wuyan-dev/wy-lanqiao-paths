## 1、参赛对象&组别

看这里，其实就是在通知一件事情：

面向所有的本科生、研究生、高职高专学生。每位学生要配一位指导老师。（官方的要严谨嘛，所以就说的很精准，**我们只需要关注重点就可以了**，有些细节过一下就好）

**接着：**

如果你是研究生，就只能报研究生组。

如果你是本科生，就报 大学 B 组；自己的学校是 985、211 的话，只能报 大学A组或者研究生组。

如果你是职高专科生的话，就只能报 大学 C 组。压力小。

**所以这个还是很人性化的，你不用太过于担心，你的对手会强到你根本面对不了的情况**。唯一感觉有点压力的的就是同一个层级的，**比如你是大一，人家是大三**；还有就是进入大学前就自学过的或者家里报班的。**不过这些人是占少数的**。

**而且**，**它这个是有获奖比例的**，只要做好自己的，**成为好的那一部分人其中之一就差不多了**。这样，压力又降低了很多。

## 2、赛制和竞赛形式

**赛制，核心就一个：是 IO 赛制**。什么是 IO 赛制呢？就是 有些编程题，它是你要全部写对了它才给分，但是 IO 赛制它不这样，它内置了多组 测试用例（就是用来测试的数据），**有多少组数据通过，就能得到多少分**。

然后有些地方还有校赛选拔，我们学校参加的是直接省赛的。省赛和国赛都是全程 4 个小时的比赛。

**竞赛形式：**就是去到一个线下集中的 比赛点，有可能在自己学习，也有可能在别的学校，我第一次参加就是在 本校，后面参加都是去 云南大学的。**不用自己带电脑**，直接去到那里，按照要求登录网址，等待比赛开始，然后集中精力比赛， 4 个小时。

<callout emoji="💫">
**注意比赛必须准备的：**这个官方都会发信息，**注意查看官网大赛通知**，他们也会通过短信的方式提醒你。
</callout>

## 4、赛题形式

**赛题就包含 结果填空题 和 编程大题**。

- **结果填空**，就是你**可以用不违反规定的任何方法**，包括使用电脑上的计算器，**算出答案，填上去就可以**。也可以使用编程的方式，解出答案填上去。**这就是下面考题范围说到的一个点：考你实际解决问题的能力**。
- **编程大题**，**就只能老老实实写程序代码提交了**。**好处就是 IO 赛制（填空题是答案对才有份，没有赛制的说法）**，否则整场考下来，可能你就只能得到 填空题的分数，甚至填空题都拿不到分。我国赛的时候填空题是 0 分。哈哈哈。
- **填空题，近年来，一般就是两道**，一道 5分，共 10 分。编程题，一般是 10 分，15 分，20 分，25 分，30 分。**编程题**大概就是这样，**它不是固定的**。

## 5、赛题考察范围

**接下来重点来了**，**这也是我所看到过的资料里面，没有介绍过的**，可能他们报班的也不会深入去研究这个 。我把它研究得比较透了，所以当时我比赛有了比较明确的方向去补充自己需要的知识点，才能让我同时准备两个比赛，用差不多 10 天的时间两个比赛都拿到 省一。（另一个比赛是智能体开发，我也有课程）

**总结下来，就是三个点：**

<callout emoji="✍️">
1. **解决实际问题的能力。**
2. **算法和数据结构的灵活运用能力。**
3. **Java 软件开发基础**、**计算机算法**及**数据结构**。

   - **Java 软件开发基础：**包含使用 Java **编写程序的能力**。
</callout>

**第一点：你需要具备解决实际问题的能力，这一项我觉得更多的是针对 填空题设置的，当然 编程题 也是会考察到的**，比如，你不会算法，但是你会暴力（就是**按照自己的思路**去**写一个能解决一部分数据的程序代码**）、你会数学思维，直接读题目，想出数学公式，用编程实现一下，这些也算是解决实际问题的能力。

**第二点：算法和数据结构的灵活运用能力。**个人感觉：拿到国家三等奖，这一部分是不需要了解得多深的。**但是不得不了解，至少你必须能写出来一些简单的算法**。

然后，**算法上我觉得这些更多的定位是一个思想**，你看那个模版代码基本上没多大帮助，因为那是别人总结出来的，**只有你自己去解决过一道题，有了场景，才更好的去理解这种算法**。【所以，刷题练习很重要】

对于数据结构，它不是有一个性能分吗，这个的选择就是觉得你的代码能在 1 s 内跑完还是 在 3 s 内跑完。

<callout emoji="💫">
## 补充：
- **算法：**是程序的灵魂，是对操作的描述，即要求计算机进行操作的步骤。是解决问题的**步骤与策略**——回答“**怎么一步步做**”。
- **广义上来说，为解决一个问题而采取的方法和步骤（本质上就是按照你的思路编写出来的正确的代码），就称为算法**。**但是因为我们写的算法，不是最好的，所以要去学人家总结出来的**，世界公认的经典算法。**所以我说 这一块 对于拿到稍微好一点的奖项来说限制不大**。
- **数据结构：**对数据的描述。是数据的**组织与存储方式**及其支持的操作——回答“**数据怎么放、放好之后能高效地做什么**”。
- 二者在**思想层面都是语言无关**的；**因编程语言而异的只是具体实现**。（**所以就涉及到了第三个能力**）
- 算法与数据结构相互咬合：**算法的效率由它依赖的数据结构决定，数据结构的价值由操作它的算法体现**。
**程序员：**数据结构 + 算法 + 程序设计方法思路（解决实际问题的能力，运用算法和数据结构的能力，业务理解程度） + 语言工具（比如Java，第三个要求的能力）。
</callout>

**第三：使用工具编写代码去实现的能力。这里其实是最适合去锻炼的，这里练的差不多，算法在会一点，然后 再去用点偷分技巧，有自己的一份策略安排或者思考，这基本上就是国三的层次。**

接着，以上两个对于软件赛来说，无论是哪一种语言，都是相同的，第三点，才是区分开的，因为 **语言本身就是一种实现工具**。**使用 Java 去解决这些问题，这就需要你去熟悉 Java 语法知识（也就是写代码的基础）**。

如果是 Python 组，那就是 使用 Python 去编写程序的能力。

发现没有，这就是核心。
