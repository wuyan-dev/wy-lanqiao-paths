# Java 组：从省一到国奖 · 课程说明与大纲

### 先认识一下我

朋友们好啊

**我是谁。** 我不是第一次参赛：第一次软件赛只拿了省二，智能体开发没获奖；第二次才拿到软件赛省一和智能体开发省一，然后两个国三。所以这份课程里说的「第一次参赛」，指的是你，不是我——我走过的是「省二 → 省一 → 国三」这条路。这段经历写在我从拿到省一再到拿国三的经历里。

我接连备战了蓝桥杯 Java 组和智能体开发两个赛项。那段时间我还在备考软考高级系统架构设计师——很遗憾，没过；不过软件设计师过了，学校奖励了我 1000 元。

从省一到国奖，我的经历有点"密集"：Java B 组省一、智能体开发省一、国家三等奖，几乎都挤在那几天里，前后只差几天。老师奖励了我 800 元；学校报销了我所有的参赛费用，两个省赛、两个国赛，一个 300 元，一共汇给我 1200 元。

所以算下来，我只是投入了时间和精力，学到了技术，拿到了荣誉，花了点小钱。另外，竞赛对保研和综测都很加分。这一点，懂的人自然懂。

**这份课程能给你什么。** 那这份东西是什么？它不是课，也没有班可以报。我买过一堆资料，看一眼就给我整焦虑了，我不想让你再焦虑一次。这里只有三样东西：一份从 0 到拿奖的思路，一份我学完之后从头梳理的 Java 编程基础笔记，一条我已经走通的路。

路我趟过了，剩下的是你自己走。你应该是自己的主人。

## 一、课程大纲

> 备赛的时候，大概会卡在这几个地方：
>
> - 不知道省赛考什么，学了一堆用不上。
> - 填空题拿不到分，编程题只会暴力。
> - 真题刷完就忘，没有按题型总结。
> - 考场时间不够，会做的题也拿不稳。

还有一句，写在第 2 节：

> 有很多人拿不到奖项的太多了，都是只是停留在知道这个比赛，知道 蓝桥官方自己登录页的那个网址，其他就啥都不知道了，怎么备赛也不知道，B站上那些搜，也都是 二次创作来的，有的还是为了引流去报班。

下面每一条，对应的是这几件事分别在哪一节被解决。**路线 A（第一次参赛 → 省一）看 01–07；路线 B（省一 → 冲国奖）直接看 08，回头对照 07。** 顺序别乱，照着走就行。

### 01｜不知道这堆资料该怎么用，也不知道自己适不适合

第 0 节：课程说明

先把「这是什么、不是什么、谁适合、按什么顺序读、大概要花多少时间」讲清楚。别一上来就扎进知识点里，方向错了，越努力越偏。

### 02｜只知道蓝桥杯这个名字，不知道值不值得打、什么时候报名

第 1 节：认识下这个比赛

官方宣传 PPT 我整理了一遍：比赛是什么、加分保研就业这些实打实的好处、6 大赛项 30 个科目里你在哪、软件赛填空 25% + 编程 75%、奖项比例、第 18 届的时间线和报名流程。括号里是我自己的补充，哪些是真有用的，哪些过一下就行，我都标了。

### 03｜官方文档一堆字，看不出 Java B 组到底考什么能力

第 2 节：带着看官方文档认识自己参加的赛道

带你把官方《竞赛规则及说明》从头过一遍，重点在「赛题考察范围」那三个能力点：解决实际问题的能力、算法和数据结构的灵活运用能力、用 Java 把程序写出来的能力。这一块是我研究得最透、也是我看到过的资料里基本没讲过的——知道考什么，才知道该补什么。顺便把组别、IO 赛制、机器环境、考纲、官方免费题库、奖项比例都对齐。

### 04｜环境装不明白，Eclipse 不熟，到考场才发现提交形式搞错了

第 3 节：环境准备 & Eclipse 快捷键 & 实际比赛提交的形式

官方环境包（JDK 8 + Eclipse 2020-06）从下载、装 JDK、配环境变量、绿色版 Eclipse、建项目写第一个 HelloWord，一步一步带图。还有我常用的那几个快捷键，以及填空题填答案、编程题交完整 Main 类代码到底长什么样。平时就按这个环境练，别到考场才发现 IDE 不熟。

### 05｜真题一堆、知识点一堆，不知道先学什么，也不知道要不要花那个钱

第 4 节：进一步认识（赛题）与制定计划

这节是动手的总开关，三件事，按 1 → 2 → 3 来：

1. **先用大概 3 天把历年真题过一遍，只整理不做题。** 目的在于对整套赛题形成整体认识，有自己的决断：针对每道题，把场景、考的是什么、标签给它打好。我当时就是用了 3 天做这件事。整理完，才开始制定自己的计划。
2. **学习。** 数据结构与算法不用系统地学，它不是面向比赛的，按考纲让 AI 给你一份学习资料就行，提示词我写好了；Java 编程基础按我给的百度网盘课程，**用差不多 8 天的时间来学完**，案例要跟着做、笔记要记好方便复习，最后那个 ATM 项目可以不做，这部分和算法那部分一起学。至于蓝桥的学习会员、刷题会员，我觉得现在 AI 那么强大，再加上我给你的经验，没必要，只是需要自己多做些努力罢了，况且你在这期间也会学到很多。
3. **练习。** 建立两个题库（不要忘记标签）：填空题单独整理成一个，编程题单独整理成一个，按自己锁定的题目重点练。刚开始肯定是很费的，先自己读一下题目，思考一两分钟，直接让 AI 给解题思路和代码（要有注释以及分析），你直接去理解是如何这么做的；慢慢的延长思考时间，自己写一下，实在不会至少把自己的思路写下来发给 AI，理解了再自己不看代码编写一遍。

后面还有分题型拿分策略：两道填空题是普通人最容易拿分的点，编程题前两道用暴力就能解决，先保底。你的计划应该根据自己的能力情况制定，哪些可做、哪些不可做，这个就是非常核心的拿分策略。

### 06｜Java 基础不牢，想查漏补缺，但缺一份能对着定位的笔记

第 5 节：我自己整理出的 Java 编程基础

接上一节：那 8 天网课学完，当时的情况是这样的，我觉得自己的 Java 编程基础还不够，我就从头到尾梳理了一遍——进制转换、数据类型、运算符、输出语句、流程控制、数组、方法、API、Arrays，还有我自己那套「复盘 → 思考 → 输出 → 复盘」。它本身就是这种样子的，所以更有参考价值，自己梳理的时候定位就更加准确。它不是教材，卡住了再翻，别从头读到尾。

### 07｜省一到底要多少分，考场上 4 小时怎么分

第 6 节：我的计划：Java B 组软件开发省一攻略

赛题考查范围、程序设计竞赛考纲、省奖/省一/国奖/国一分别要会什么、题型分值和目标分数拆解，还有「输家思维-保底」：按数据规模拿部分分，会正解写正解，不会正解写暴力循环骗分。附 4 小时黄金时间轴和查错清单。我的判断是：省赛只要你会暴力，只要你能看懂题，只要你代码不是乱写，就是能拿到省一。

### 08｜省一之后，怎么在两周左右往国奖够

第 7 节：我的计划：Java B 组软件开发国奖攻略

国赛的竞争和获奖比例、题型分值、目标分解（国三 45 / 国二 50 / 国一 70）、拿奖参照物、目标与定位、准备清单（数学、基础算法、搜索、DP、数据结构、图论），以及怎么刷题。我当时定的目标是国二，最后国三——那两周是包括我研究历年所有真题的时间在里面的。所以，越早准备越好。

> 省一攻略和国奖攻略里，有一套一样的考场打法：输家思维-保底、4 小时时间轴、查错阶段、解题技巧和备考策略。这不是凑字数，是同一套方法我在省赛和国赛两个真实场景各跑了一遍，两处都留着，你对照着看，才知道省赛和国赛的取舍差在哪。
