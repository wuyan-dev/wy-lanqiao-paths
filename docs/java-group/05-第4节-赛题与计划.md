## 3、怎么练习

这个时候自己心里大概有了些感觉，重点选最近几年的几套进行练习，其他的可以按照标签去题库里面找。

练的时候，如果把我踩的坑都尽量避免，那你的成就一定比我高。

- **练习技巧：建立两个题库（不要忘记标签）**

  - 填空题：我是这样的，单独把历年所有的填空题整理出来放在一起，作为一个自己的题库。
  - 编程题：同样的，单独再把编程题整理出来作为自己的一个题库。

    - **这里的一个经验：**编程题按照自己锁定的题目重点整理，那些看都看不懂的，国奖之前几乎不用去碰都可以的。能力提升上来了，再去啃也可以。

- **目标（也是我的经验教训）：**

  - **必须把这些填空题的思路给吃透**。如果你数学比较强，再加上代码实现能力，我觉得肯定没问题的，但是就是一定要多练。如果你填空题把握的好一点，两道题几乎每次都能自己解出来一道，那就比我强了。

- **代码就可以当作计算器**，你可以编写代码来解决大数据的处理，**比计算器还灵活**，这也是编程的本质所在。

- 我没能吃透，导致一个大数的处理，我明明思路是对的，数据小的话编程也是能出来，但是通常填空题给到数据范围非常大，所以直接给内存整崩了，想不到解决办法，就没能做出来。

- **⭐最后：**

  - **第一：**刚开始肯定是很费的，所以这个时候重点是在于一个流程：先自己读一下题目，思考一两分钟，直接让 AI 给解题思路和代码（要有注释以及分析），你直接去理解是如何这么做的。
  - **慢慢的：**你就可以自己写延长思考的时间，自己写一下，实在不会的至少把自己的思路写下来，发给我 AI，让它给你指导，然后自己理解了（哪里不理解就直接追问 AI ，直到懂为止）再自己不看代码编写一遍。**慢慢的你就成长很多了**。

# 02|分题型拿分策略

**两道填空题：普通人最容易拿分的点。**

- **题目描述不多，通常就只有一个难点。**
- **解决了那个难点就能拿分** → 要尽可能的去掌握。

**编程题：按难度分层规划。**

- **前两道：**只有暴力都可以解决，靠自己的思路，只要你编码能力没问题，都可以解决的，所以**这两道题也要尽可能的掌握**。
- **第三题起：**可能开始加难度，但是注意，有时候这个题目的难度也不是固定排列的，你去整理历年真题的时候就能感觉到了。
- **后面的题：**可以自己规划好，不用想着把所有题目都从头做到尾。

- 核心拿分策略：你的计划，应该是根据自己的能力情况制定，哪些可做，哪些不可做，哪些可做的都保底了的情况下可以去试一试，这个就是非常核心的拿分策略。

我比赛的时候，拿到压缩包，解压后拿到 PDF 题目文件，第一件事就是看完所有题目，看哪些自己好做，哪些可以冲一冲，哪些直接写一下输入输出，骗点分（这些的概率很低，但是万一真给自己拿到了就很不错了），然后开始做。
