### 查错阶段

每年都有平时贼牛的选手因为下面这几条含恨退役，必须刻在DNA里：

1. **类型溢出：**

<callout emoji="🧑">
**描述：求和、累乘直接用 long**，不用 int，避免溢出
**解释：**int 范围太小，算着算着数值会爆掉变成负数；long 范围大得多，竞赛必须优先用 long 存结果。
**案例：**int a=1e9; int b=1e9; a+b 会溢出；改成 long 就正常。
</callout>

1. **数组越界：**

<callout emoji="🧑">
**描述：**数组长度比题目给的 N **多开 10** 个以上，比如 N=1e5，开 new long [100010]
**解释：**下标不小心多跑一位就会崩溃，数组开得比题目要求大一点，留安全余量。
**案例：**题目说 N≤100000，你就开 100010 长度，别刚好开 100000。
</callout>

1. **大数组内存：**

<callout emoji="🧑">
**描述：超大数组用全局成员变量 / 静态变量**，避免方法内栈溢出
**解释：**Java 方法里开数组用的是栈空间，很小容易爆；全局 / 静态存在堆，空间大不会崩。
**案例：**不要在 main 里写 int [] a = new int [1000000]，要写在类下面、方法外面。
</callout>

1. **调试代码：**提交前删除所有`System.out.println`调试语句
2. **代码规范：**main方法正常结束即可，Java无需return 0，但要确保无异常

# 战前冲刺

## 二、高频考点与暴力解题

### 2.1 高频考点分析

#### 1、模拟与思维

- 概念：模拟题通常要求学生根据题目描述实现具体的算法或逻辑，**考察对问题本质的理解和抽象能力**。
- 解题技巧：

  - 掌握常见问题的模拟方法，比如游戏、物理现象等。
  - **能够将实际问题转化为可计算的数学模型**。

#### 2、基础数据结构

- 概念：数据结构是组织和存储数据的方式，如数组、链表、栈、队列、（难）树、图等。
- 解题技巧：

  - **熟练掌握每种数据结构的特点和适用场景**。
  - **能够根据问题需求选择合适的数据结构**。

#### 3、基础算法

- 概念：算法是解决问题的步骤或方法，如排序（自动排序）、二分、递归等。
- 解题技巧：

  - **理解算法的原理**。
  - **能够根据问题的特点，选择合适的算法，并分析其时间复杂度和空间复杂度**。

#### 4、搜索算法

- 概念：搜索算法是解决问题的策略，如深度优先搜索（DFS）、广度优先搜索（BFS）等。
- 解题技巧：

  - **能够识别适合用动态规划解决的问题**。
  - **熟练运用动态规划的基本思想和技巧**。

### 2.2 暴力解题

#### 1、概念

- 暴力解题法是一种**通过穷举所有可能的情况来解决问题的方法**。
- 通常适用于问题规模较小或对解的效率要求不高的情况。

#### 2、步骤

- **确定范围：明确解的范围，例如数字类型的最大值和最小值，字符类型的字符集。**
- **找出条件：分析题目中的限制条件，例如数字的取值范围、字符的特定属性等。**
- **明确输出：确定输出结果的数量、类型、次序和格式。**
- **暴力枚举：在确定的范围内，逐个检查每个元素，直到找到满足条件的解。**

#### 3、优缺点

- 优点：实现简单，逻辑清晰，易于理解和调试。
- 缺点：当问题规模较大时，效率低下，可能需要大量的重复计算。

#### 4、注意事项

- 在使用暴力解题法时，应该**尽量去优化范围和条件**，以减少不必要的计算。
- 对于一些可以通过观察和思考直接找出规律的题目**就不要使用**，暴力解题可能不是高效的方法。

#### 例题 1：维纳猜年龄（原题）

###### 题目描述：

美国数学家维纳 (N.Wiener) 智力早熟，11 岁就上了大学。他曾在 1935\~1936 年应邀来中国清华大学讲学。一次，他参加某个重要会议，年轻的脸孔引人注目。于是有人询问他的年龄，他回答说：“我年龄的立方是个 4 位数。我年龄的 4 次方是个 6 位数。这 10 个数字正好包含了从 0 到 9 这 10 个数字，每个都恰好出现 1 次。” 请你推算一下，他当时到底有多年轻。

###### 解题思路：

- 确定范围：从 10 岁开始枚举，最大不超过 30 岁，因为 30³ 是一个 5 位数
- 判断条件：年龄的立方是 4 位数，年龄的 4 次方是 6 位数，并且这两个数包含 0-9 这 10 个数字，每个数字只出现一次。

#### 例题 2：猜年龄（变形例题）

###### 题目描述：

小明带两个妹妹参加元宵灯会。别人问他们多大了，他们调皮地说：“我们俩的年龄之积是年龄之和的 6 倍”。小明又补充说：“她们可不是双胞胎，年龄差肯定也不超过 8 岁啊。” 请你写出：小明的较小的妹妹的年龄。

###### 解题思路：

- 设两个妹妹的年龄为 i 和 j，则 i \* j = (i + j) \* 6
- 年龄差不超过 8 岁：|i-j| <= 8

##### 例题 1 代码

```Java
/**
 * 维纳年龄问题求解
 * 条件：年龄立方为4位数，4次方为6位数，10个数字包含0-9各一次
 */
public class WienerAge {
    public static void main(String[] args) {
        // 遍历年龄范围：10~30岁
        for (int age = 10; age <= 30; age++) {
            // 计算立方（4位数）
            int cube = age * age * age;
            // 计算4次方（6位数，用long避免溢出）
            long fourthPower = (long) cube * age;

            // 条件1：立方为4位数
            if (cube < 1000 || cube > 9999) {
                continue;
            }
            // 条件2：4次方为6位数
            if (fourthPower < 100000 || fourthPower > 999999) {
                continue;
            }

            // 拼接两个数的所有数字
            String allDigits = cube + String.valueOf(fourthPower);
            // 条件3：10个数字包含0-9各一次，无重复
            if (isAllDigitsUnique(allDigits)) {
                System.out.println("维纳的年龄是：" + age + "岁");
                System.out.println(age + "³ = " + cube);
                System.out.println(age + "⁴ = " + fourthPower);
                break;
            }
        }
    }

    /**
     * 判断字符串中的数字是否包含0-9各一次，无重复
     * @param str 待检查的数字字符串
     * @return 符合条件返回true，否则false
     */
    private static boolean isAllDigitsUnique(String str) {
        // 长度必须为10
        if (str.length() != 10) {
            return false;
        }

        boolean[] used = new boolean[10];
        for (int i = 0; i < str.length(); i++) {
            int digit = str.charAt(i) - '0';
            // 数字重复，直接返回false
            if (used[digit]) {
                return false;
            }
            used[digit] = true;
        }
        return true;
    }
}
```

```Java
/**
 * 猜年龄变形题求解
 * 条件：年龄之积是和的6倍，非双胞胎，年龄差≤8岁
 */
public class SisterAge {
    public static void main(String[] args) {
        // 遍历妹妹年龄范围（合理年龄：1~20岁）
        for (int i = 1; i <= 20; i++) {
            for (int j = i + 1; j <= 20; j++) { // j > i，避免重复，非双胞胎
                // 条件1：年龄之积是和的6倍
                if (i * j != 6 * (i + j)) {
                    continue;
                }
                // 条件2：年龄差不超过8岁
                if (j - i > 8) {
                    continue;
                }

                System.out.println("两个妹妹的年龄分别为：" + i + "岁、" + j + "岁");
                System.out.println("较小的妹妹年龄为：" + i + "岁");
                return;
            }
        }
    }
}
```

```Java
/**
 * 门牌制作问题（2020蓝桥杯省赛）
 * 统计1~2020所有门牌号中字符'2'的总个数
 */
public class DoorPlate {
    public static void main(String[] args) {
        int total = 0; // 统计字符'2'的总个数

        // 遍历1到2020的所有门牌号
        for (int num = 1; num <= 2020; num++) {
            // 将数字转为字符串，方便遍历字符
            String numStr = String.valueOf(num);
            // 累加当前数字中'2'的个数
            total += countChar2(numStr);
        }

        System.out.println("总共需要字符'2'的个数为：" + total);
    }

    /**
     * 统计字符串中字符'2'的出现次数
     * @param str 待统计的字符串
     * @return 字符'2'的个数
     */
    private static int countChar2(String str) {
        int count = 0;
        // 遍历字符串的每一个字符（核心：遍历字符串的方法）
        for (int i = 0; i < str.length(); i++) {
            char c = str.charAt(i); // 获取第i位的字符
            if (c == '2') { // 判断是否为字符'2'
                count++;
            }
        }
        return count;
    }
}
```

```Java
    public static void main(String[] args) {
        // 1949年10月1日 星期六 → 6
        int week = 6;
        int count = 0;

        // 从1949遍历到2012
        for (int year = 1949; year <= 2012; year++) {

            // 如果这一年的国庆节是星期日，计数+1
            if (week == 0) {
                count++;
            }

            // 计算下一年的星期
            if (isRun(year)) { // 今年是闰年 → 明年星期+2
                week = (week + 2) % 7;
            } else {            // 今年是平年 → 明年星期+1
                week = (week + 1) % 7;
            }
        }

        System.out.println(count);
    }

    // 判断闰年（背会！）
    public static boolean isRun(int year) {
        if (year % 400 == 0) return true;
        if (year % 100 == 0) return false;
        if (year % 4 == 0) return true;
        return false;
    }
}
```
