# Java 组：从省一到国奖

**省一，我拆出来只要 30 分。** 满分 100、10 道题、4 小时——很多人不是不会，是不知道该拿哪些分。

两次参赛：第一次省二，第二次 Java B 组省一 + 国三。这份笔记是中间那段路：怎么读官方文档、怎么定计划、考场上 4 小时怎么分配。

## 上手前，先知道这四件事

**省一我拆出来只要 30 分。**
满分 100，2 道填空各 5 分，6 道编程共 90 分。你不需要做完所有题，也不需要会所有算法——按题型挑着拿分，这是第 6 节讲的事。

**省赛前 50% 有奖，一等奖进决赛。**
一二三等奖分别是 10% / 15% / 25%。意思是省一不是「前几名」，是前 10%。

**4 小时，机器判题。**
输出格式必须严格匹配，格式不对，答案再对也可能不得分。平时就按考场环境练。

**练习方式比练习量重要。**
3 天真题只整理不做题 → 8 天基础课 → 建两个题库按标签练。顺序反了，白费力气。

## 怎么开始

1. **3 天**：历年真题过一遍，**只整理不做题**。给每道题打标签——什么场景、考什么。整理完，才知道该补什么。
2. **8 天**：Java 基础课跟着敲，算法一起学。数据结构与算法不用系统学，按考纲让 AI 给你一份就够。
3. **一直练**：建两个题库，填空一个、编程一个，都打标签。先自己想一两分钟，再要解析；看懂了合上代码自己写一遍。

> 别拿「10 天两个省一」当你的时间表。那是我把考纲研究透、还同时准备两个赛项之后的结果。省赛在 4 月，报名 12 月 18 日截止——你有多少天，日历上自己数。

## 我踩过的坑

第一次参赛只拿省二。国赛目标定的国二，最后国三。软件赛填空拿过 0 分，一道大数题把内存整崩了。

写这些不是自谦，是想说：下面的判断是踩过之后留下的，不是抄来的。

## 适合谁

- 第一次报名，连考什么都不知道
- 已经拿到省一，想冲国奖
- 想要一份能对着定位的 Java 基础笔记

**不适合**：找押题、找获奖承诺的。这里没有。
