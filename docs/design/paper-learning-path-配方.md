## 风控词

禁止：任何获奖承诺词、绝对化用语和「必 / 稳 / 包 / 保」类承诺性表述。
可用：目标省一、冲国奖——这是「目标」表述，不是承诺。不要改成承诺性表述。

「填空保底」里的「保底」是算法竞赛术语（按数据规模拿部分分），用户原文有，可保留；但不要拿它做宣传承诺。


## 常见坑

- numpy 2.x 用 `np.ptp(arr)`，不要用 `arr.ptp()`。
- 撕纸边要「低频起伏 + 高频碎口 + 偶发深撕口」三者叠加；只加正弦会变成规则波浪，不像撕的。
- 马克笔必须**一整块笔触**，不能叠多个圆角矩形——叠出来是横条胶带感。做法：画一个圆角矩形 → 高斯模糊 → 二值化 → 啃小缺口 → 叠淡刷痕。
- 齿轮齿太短会变成太阳花，`r_out*1.34` 的齿长要保留。
- 左下蓝布角别画太大，会抢戏。
