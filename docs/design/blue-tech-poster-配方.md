## 风控词（硬红线）

### 承诺词

禁止：任何获奖承诺词、绝对化用语和「必 / 稳 / 包 / 保」类承诺性表述。
可用：目标省一、亲历两个赛项、样题各跑一遍、评分五档拆解、提交物清单——基于事实的表述。

### 品牌与赛事名称隔离（硬红线，曾踩坑）

- **绝不能**把作者署名与赛事方名称写在一起（包括用间隔号、斜杠、连字符连写，或放进同一署名区）。这会让读者误以为赛事是作者创立的，属于侵权风险。
- 左上品牌区：只有署名（`brand`）和中性身份说明（`brand_sub`），如「梧焰」/「课程主讲 · 智能体开发」。不放赛事名、年份、日期。
- 右上角的 `badge`：不放赛事信息。留空字符串时脚本不绘制；要用只能写中性课程信息。
- 赛事名称**只允许**出现在中部的课程介绍（`subtitle`），作为客观描述，如「蓝桥杯赛事 · 十七届 / 十八届样题各跑一遍 · 7 节完整路径」。
- 判定标准：把品牌区和课程介绍区分开看，读者不会把赛事名读成作者品牌的一部分。


## 常见坑

- numpy 2.x：`ndarray.ptp()` 已移除，用 `np.ptp(arr)`。
- 黄字不能只画一次：先 `glow_text(... stroke=(255,255,255), sw=8)` 垫白边，再 `d.text(... fill=YELLOW, stroke_width=1)`，否则描边发灰。
- 数据卡顶部彩条要先用圆角 mask 裁，再 alpha_composite，否则彩条溢出圆角。
- 副标 / 卡片位置是踩过坑调出来的，不要在没做目视校验前改动。
